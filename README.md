# Sri Sathya Sai Seva Samithi, Premsadan — Visakhapatnam

Website for Sri Sathya Sai Seva Samithi at Premsadan Mandir, MVP Colony, Visakhapatnam.

## Development

Requires Node.js and npm.

```sh
cd ssssovizag
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
